# OTTPA BOARD
The OTTPA Board will oversee rules & safety for all classes, purse & payout recommendations, etc. and forward all info to the Executive Board through the OTTPA board President. Terms are for 3 years.

***NOTE:*** If a class board member changes to a different class, is no longer an OTTPA member, the class will elect a new class board member at the next annual OTTPA meeting.
